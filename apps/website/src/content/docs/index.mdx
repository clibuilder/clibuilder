`clibuilder` builds command line applications from **commands**. Each command declares its own
arguments and options with the [`t`](/clibuilder/api/t/) type descriptors, and its config with any
[Standard Schema](https://standardschema.dev). The types of
what `run()` receives are inferred from those declarations — no separate type definition to keep in
sync.

```ts
import { cli, t } from 'clibuilder'

cli({ name: 'greet', version: '1.0.0' })
  .default({
    arguments: [{ name: 'name', description: 'who to greet' }],
    options: { times: { description: 'how many times', type: t.int(), default: 1 } },
    run(args) {
      // args.name is string, args.times is number
      for (let i = 0; i < args.times; i++) this.ui.info(`hello, ${args.name}`)
    }
  })
  .parse(process.argv)
  .catch(e => process.exit(e?.code || 1))
```
